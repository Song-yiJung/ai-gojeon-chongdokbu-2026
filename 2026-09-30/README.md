# 1회 — 원본 이미지에서 읽을 수 있는 텍스트로

2026년 9월 30일

종이에 인쇄된 한 면이 기계가 다룰 수 있는 글자가 되기까지를 한 번에 따라간다. 교재 PDF를
면 단위 이미지로 쪼개고, 그 이미지를 LLM에 넣어 글자를 뽑고, 뽑힌 글자를 원본과 대조해
확정하고, 확정된 텍스트를 강독 노트의 한 구획으로 앉힌다. 저장소에 남는 것은 이 가운데
확정 텍스트까지다.

대표 실습 대상은 『臨時財産整理局事務要綱』 교재 34면(원본 二六·二七)이다. 다루는 범위는
교재 30~45면이며, 이 가운데 42~45면(원본 附錄 18~25면)이 강독 대상이었다.

본문은 한자와 가타카나를 섞은 훈독체이고, 附錄의 往復文書는 대부분 소로분(候文)이다.
같은 자료 안에서 문체가 갈리므로 판독 기준도 달라진다.

## 파일

| 파일 | 무엇인가 |
|---|---|
| `1회_강의슬라이드.pptx` · `.pdf` | 수업에서 띄운 슬라이드 33장 |
| `1회_강의안.docx` · `.pdf` | 진행 순서와 설명 |
| `교재PDF_이미지변환.ipynb` | PDF를 면 단위 이미지로 쪼개는 Colab 노트북. 교재 한 면 전체와 그 안의 원본 좌·우 면을 따로 저장한다 |
| `교재36-45_이미지추출_프롬프트.txt` | 이미지에서 글자를 뽑을 때 LLM에 준 프롬프트 |
| `교재30-45_확정텍스트.txt` | 추출 결과를 교재 이미지와 대조해 확정한 판독 텍스트 |
| `임시재산정리국_사무요강_원문_위키.txt` | 위키에 올린 판독 원문 |
| `중간과정/` | LLM이 이미지에서 글자를 뽑는 중간 화면 |

강독 노트는 강독 쪽 산출물이고 강의 녹음에서 나온 내용을 담고 있어 이 저장소에 두지
않는다.

## 판독 텍스트의 표기 약속

`교재30-45_확정텍스트.txt`를 읽을 때 알아 두어야 할 것.

- 판별이 어려운 글자는 `(?)`로 표시한다.
- 괄호 안의 작은 활자는 `〔 〕`로 감싼다.
- 인쇄된 줄바꿈을 그대로 따르지 않고 문단 단위로 잇는다.
- 강조 점은 옮기지 않는다.

이 네 가지가 이미 하나의 판단이다. 무엇을 옮기고 무엇을 옮기지 않을지 정한 것이기
때문이다. 2회 수업은 이 지점에서 이어진다.

## 남는 것

`교재30-45_확정텍스트.txt`가 이 회차의 산출물이다. 2회 수업은 이 텍스트에서 시작한다.
