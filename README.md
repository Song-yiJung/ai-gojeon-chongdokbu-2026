## 이 저장소에 있는 것

강좌의 핵심 교과는 둘이다. **조선총독부 문서 강독**과 **강독 산출물의 AI 데이터 전환**.
이 저장소는 **뒤쪽, 데이터 전환 실습 세 차례**의 자료와 산출물을 모은 것이다. 강독 자체의
기록은 들어 있지 않다.

수강생이 **자기 사료를 자기 데이터로** 만드는 과정을 직접 밟는다. 이미 만들어진
데이터베이스를 쓰는 법이 아니라, 손에 든 자료를 데이터로 바꾸는 판단을 스스로 내리는
법을 다룬다. 도구는 LLM을 쓰되, 무엇을 남기고 무엇을 버릴지는 자료를 읽은 사람이 정한다.

| 회차 | 날짜 | 하는 일 |
|---|---|---|
| 1 | 2026-09-30 | [원본 이미지에서 읽을 수 있는 텍스트로](2026-09-30/) |
| 2 | 2026-10-28 | [텍스트에 판단을 입혀 데이터로](2026-10-28/) |
| 3 | 2026-11-25 | [그 과정을 LLM으로 반자동화](2026-11-25/) |

1회는 자료를 기계가 읽을 수 있게 만들고, 2회는 거기에 사람의 판단을 입히고, 3회는 그
판단을 프롬프트로 옮긴다. 세 회차를 관통하는 질문은 하나다. **무엇을 남기고 무엇을 버릴
것인가, 그리고 왜 그렇게 정했는가.**

1회와 2회는 공통 자료 하나를 다 같이 다루고, 3회에서는 각자 고른 일제강점기 사료로
옮겨 간다.

## 다루는 자료

『臨時財産整理局事務要綱(임시재산정리국 사무요강)』. 1911년(明治 44) 2월, 전 임시재산
정리국장관이자 탁지부장관이던 아라이 겐타로(荒井賢太郎)가 조선총독 데라우치 마사타케
(寺内正毅)에게 올린 보고서다. 임시재산정리국은 대한제국 황실 재산을 국유로 이속하는
일을 처리하기 위해 1908년 7월 탁지부에 설치되어 1910년 9월 총독부 관제 발포와 함께
폐지된 한시 기구다. 조선토지조사사업(1910~1918)의 전사(前史)에 해당하는 1차 사료다.

본문은 한자와 가타카나를 섞은 훈독체이고, 附錄의 往復文書는 대부분 소로분(候文)이다.
같은 자료 안에서 문체가 갈리므로 판독 기준도 달라진다.

서지와 이용 범위는 [자료출처.md](자료출처.md)에 적었다.
